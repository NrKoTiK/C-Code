I learnt couple of new things such as when trying to access another classes private members create a public member function (Query) that just returns the data stored in the private member. Now you can access that data.
The second thing I learnt was when trying to create the array of abilities you need a default constructor. As the variables need to be in a default state or else compiler yells at you.

The reason why we didnt consider the free helpers as queries is because they are not member functions and do not affect the objects state. We only declare query or modifiers on member functions
as they have access to objects private members and that data belonging to them. While freehelpers only have access to the object when the object is passed in as a parameter.
