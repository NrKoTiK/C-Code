In a workshop, I encountered some problems but expected error. The main problem was about inheritance. When I inherit from a class I need to copy both the base class members and the derived class members. This is done by invoking the base class copy assignment operator for each derived class ensuring a complete copy. This is how its done: (LibraryItem&)*this = (const LibraryItem&)that; This code casts the derived classes to their base class versions triggering the base class copy assignment operator.
